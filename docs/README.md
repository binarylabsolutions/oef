# Docs

Planning documents for the Open Education Studio ("the studio", working name): a non-profit that gives education creators in Pakistan a free backend of volunteer contributors, tools and systems.

This folder is the planning half of the repo. Platform code will live alongside it later.

## Conventions

- One topic per file, numbered in reading order.
- Every creator gets a folder under `creators/<handle>/` with a `proposal.md` and a `growth-plan.md`.
- Docs state the current working position. Undecided questions live only in [open-questions.md](open-questions.md), never inside the other docs.
- Dates are written in full (e.g. 30 Sep 2026).
