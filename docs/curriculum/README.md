# Software engineering curriculum proposal

*Last updated: 25 Oct 2026 · Proposal, not final*

A proposal for a software engineering degree in the AI era, written for any university. AI now handles much of the code-writing, the way compilers took over assembly, so the degree moves its weight from typing code to systems knowledge and engineering judgement. Students still hand-code enough to become fluent.
